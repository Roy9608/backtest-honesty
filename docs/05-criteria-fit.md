# 铁律 5：判据必须适配策略类型

**这是最隐蔽的一类错误：指标算对了，但用错了场景。**

## 为什么最隐蔽

因为它**看起来像是在严谨**。

用"完美标准"去评判一个"可用方案"，是最容易犯、也最不容易被发现的错误——
因为你的动作（做一个检查、给出一个判断）看起来完全正确，
错的是**你选的这把尺子本身**。

## 不同策略类型，看不同的指标

| 策略类型 | 该看 | **不该看** |
|---|---|---|
| **趋势跟随** | 单笔期望、盈亏比、**最大单段亏损** | ❌ 收益均匀度、胜率、Top5 集中度 |
| **均值回归** | 胜率、稳定性、**Top5 集中度** | ⚠️ 单笔期望（可能很小） |
| **高频 / 套利** | 单笔期望、成交率、成本占比 | ❌ 单段收益（时间尺度不匹配） |

**★ 用错判据 = 用错误的标准否定一个可用策略。**

## 一个真实案例

**现象**：某趋势策略在 6 段测试中只有 3 段为正；Top5 的单日收益占总净 α 的 143.9%。

**错误的第一反应**：判定为"盈利极度集中，不是能赚钱的策略"。

**正确解读**：

| 观察 | 数值 | 含义 |
|---|---|---|
| 三个亏损段合计 | −4.86% | 亏损被有效截断 |
| 最大单段亏损 | −2.91% | 可控 |
| 一个大赚段 | **+73.41%** | 利润奔跑 |
| **形态** | **截断亏损、让利润奔跑** | **趋势策略的正常形态** |

**趋势跟随策略的数学本质：大部分时间小亏，少数时间大赚。**

> **要求"收益均匀""每段都赚" —— 那才是过拟合，实盘必然失效。**

## 出结论前先问三句

1. **我用的判据，适配这个策略类型吗？**
2. **这个"问题"是策略的缺陷，还是它的固有特征？**
3. **如果换成有经验的从业者，他会怎么判断这件事？**

**特别是第 2 句**：趋势策略的"集中"、高频策略的"单笔薄"、
均值回归的"低盈亏比"—— **都是固有特征，不是缺陷。**

## 趋势策略的正确判据

| 判据 | 健康值参考 |
|---|---|
| 单笔净期望 | > 0（至少 > 成本） |
| α / 成本 | > 1.5x |
| 最大单段亏损 | 可控（如 < 5%） |
| **亏损段合计 / 最大盈利段** | **< 30%**（说明亏损被有效截断） |
| 正收益段占比 | 30–50% 即可，**不是否决项** |

## 最后一条，也是最贵的教训

> **「判据适配」不能替代「数字正确」。**

真实经历：先用错了判据去否定一个策略；纠正判据之后，
**又用一批错的数字去肯定同一个策略**。

两个错误方向相反，但根因相同：
**都是从"中间产物"直接往下推结论，没有先验证数据的产生方式。**

具体到操作：**任何合计类结论，先查「交易数 ÷ 独立机会数」，再谈判据。**
