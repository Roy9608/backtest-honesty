# 出结论前的检查清单

**逐项打勾。心里默念"这个应该没问题"是最危险的。**

---

## A. 收益归因（最根本）

- [ ] **β 基准已计算**（随机时点买入持有，持仓时长与策略对齐）
- [ ] **α = 策略收益 − β基准**，且已与成本对比
- [ ] **★ β 给了区间**（多 seed + 均匀抽样交叉核对，见铁律 8）
- [ ] **β 没有逐笔相加**（持仓重叠时会被重复计算，见铁律 1）
- [ ] **分段涨跌已看**（不只看总和）
- [ ] **收益集中度已检验**（Top1/Top3 占比）

## B. 稳健性

- [ ] **Walk-Forward 已做**（多段滚动，非单次切分）
- [ ] **正收益段数占比**已统计
- [ ] **★ 亏损段合计 ÷ 最大盈利段 < 30%？**（趋势策略的正确判据）
- [ ] **★ 参数邻域是平台还是锯齿？**（贴出相邻格子的数值）
- [ ] **★ t 值算了吗？t<2 就只能说"方向"，并写出还差多少笔**
- [ ] **最大单段亏损**已报（不是只报平均）

## C. 建模正确性

- [ ] **单仓不变量已核** —— 判据是「**交易区间是否交错**」
      ⚠️ 不是「信号数 ÷ 交易数 ≈ 1」（后者在限价模式下天然 > 1）
- [ ] **无未来函数**（没有用到未来数据）
- [ ] **分组汇总之和 = 总体合计？**（不等 → 检查是否静默丢了小组）
- [ ] **成交价口径是保守版？**（用触发分钟的市价/收盘价，不是线位价）
- [ ] **移植来的规则，「语义前提」在新策略里还成立吗？**
- [ ] **★ 「t 异常高 + 持仓异常短」同时出现时，当成 bug 查而不是当发现报**

## D. 成本与执行

- [ ] **费率已实测**，开仓/平仓方式已确认
- [ ] **毛/净分列**（毛收益为正但净为负 = 成本问题，非策略问题）
- [ ] **★ 执行方式（限价深度）对成交集的影响已测**
- [ ] **★ 收益拆成「机械价差」和「选择效应」了吗？**（见铁律 14）
- [ ] **深度 → 成交率 → 单笔净** 的完整曲线已测

## E. 风控与机制叠加

- [ ] **加风控/止损做了档位扫描吗？**（至少 6 档）
- [ ] **期望收益与尾部改善分别报了吗？**
- [ ] **该参数是平台还是断崖？**（断崖 → 不可作外推依据）
- [ ] **叠加机制前先问「作用方向冲突吗」，叠加后重跑邻域**

## F. 交付

- [ ] **判据适配策略类型**（趋势/均值回归/高频，看不同的指标）
- [ ] **所有被推翻的旧结论已清理**（语义一致性检查）
- [ ] **文档只有一个结论区**
- [ ] **报告的表格包含输出规范里的全部字段**

---

## 最后三问（出结论前必问）

1. **我用的判据，适配这个策略类型吗？**
2. **这个"问题"是策略的缺陷，还是它的固有特征？**
3. **如果换成有经验的从业者，他会怎么判断这件事？**

> **用"完美标准"去评判一个"可用方案"，是最容易犯也最隐蔽的错误 ——
> 因为它看起来像是在"严谨"。**
