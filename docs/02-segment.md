# 铁律 2：分段看行情，不要只看总和

**90 天涨 30%，不代表每天在涨。**

## 为什么

只看总和，会把"某一段行情特别好"误认为"策略适应了行情"。

一个真实例子（分段后真相立刻暴露）：

| 段 | 区间 | 标的涨跌 | 策略净收益 |
|---|---|---|---|
| 1–4 | 前半程 | 累计约 +8% | 累计约 −3% |
| **5** | **中段** | **+29.18%** | **+6.09%** |
| 6 | 末段 | −1.83% | −3.68% |

**策略唯一的大赢段，恰好是大盘涨得最猛的一段 → 收益来自 β 不是 α。**

如果只看总和，会误判为"策略有效"。

## 怎么做

```python
# 切成 N 段，看每段涨跌与策略表现
for s in range(N):
    a, b = s * L, (s + 1) * L
    chg = (px[b - 1].c - px[a].c) / px[a].c * 100
    strat = backtest(a, b)
    print(s, chg, strat.net_alpha)
```

## 两个输出要求

### 1. 正收益段占比

**这是信息量最大的一个数字。**

- 趋势策略：30–50% 即可（见 [铁律 5](05-criteria-fit.md)）
- 如果只有 1/N 段为正 → 大概率是运气，不是规律

### 2. 去掉最强段后还剩多少

⚠️ **但注意：这条只能当"提示"，不能当"否决线"。**

详细说明见 [铁律 8](08-interval.md) —— 用"去掉最强段必须仍为正"当否决线，
**等于要求"每段都赚"，那才是过拟合**，而且正好否定了趋势策略的固有形态。

**正确的用法**：它是"独立事件数够不够"的提示，不是成败判据。

## 一句话

> **分段不是为了好看，是为了让"运气"和"规律"分家。**
