# 铁律 9：执行方式（挂单深度）是策略的一部分

**「挂限价单省手续费」是一个陷阱式的乐观。**

## 机制

挂单深度同时改变两件事：

1. **入场价差**（挂得越深，买得越便宜）
2. **成交集**（挂得越深，越多的信号根本不成交 → 留下的是一批被筛选过的信号）

**这两件事方向相反，必须分别测量。**

## 实测

（365 天，单边做多）

| 深度 | 成交率 | 成交价差 | 毛收益 | **单笔净** |
|---|---|---|---|---|
| 市价 | 100% | 0.00bp | +2.29% | −0.0544% |
| **贴盘口挂单（5 tick）** | 85.1% | +0.20bp | −1.60% | **−0.0535%** |
| 深挂（8bp） | 28.6% | +8.00bp | +8.68% | +0.0817% |

**贴盘口 vs 市价：几乎完全一样。**

省下的 4bp 手续费，被"只做会成交的那批信号"吃掉了
（把市价单限制在同一成交集上，毛收益掉 4.08pp）。

> **挂得深才有用，但深挂会大幅降低成交率。**

## 分解做法

```python
# 三跑对比
m_all  = 回测(市价)                           # 基准
m_cond = 回测(市价, 但只做「限价会成交」的信号)   # 隔离选择效应
l      = 回测(限价)

选择效应 = m_cond.gross - m_all.gross
价差效应 = l.gross - m_cond.gross
```

⚠️ **这个分解含「路径重排」噪声**（跳过一个信号会改变后续入场时点），
不要把两个数字当成干净的因果分量；但它足以判断**哪个效应占主导**。

更完整的版本见 [铁律 14](14-four-way-decomposition.md)。

## 结论

**挂单深度是「信号质量 ↔ 入场价差」的取舍。**

必须测「**深度 → 成交率 → 单笔净**」的完整曲线，
并对深度轴上的**跳跃**（不是平滑过渡）保持警惕。

实例：在 50→100 tick 之间，单笔净从 −0.0430% 跳到 +0.0563% ——
**说明是换了一批成交集，不是连续改善。**

## 成交假设怎么验（不需要逐笔也能验掉一半）

| 口径 | 定义 | 用途 |
|---|---|---|
| **touch** | 价格触及限价即成交 | 上界 |
| **strict** | 必须严格穿透（`low < 限价`） | 下界（抵排队风险） |

实测：两者**逐位相同**（592 次触及中仅 5 次"恰好等于限价"，
且这些在后续分钟照样成交）。

> **K 线能验证的部分，"触及即成交"站得住；剩下的只有真排队风险，需要一个安静时刻的逐笔深度数据。**

> **别把"成交假设未验证"当成万能挡箭牌 —— 先测，测完它往往不是主要矛盾。**
