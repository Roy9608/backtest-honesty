# 铁律 13：加风控、叠机制，都必须实测

**不能靠「更安全 / 更多更好」的直觉。**

## 13.1 事故一：给策略「补硬止损」，结果把策略杀死了

一个 t=+2.07 的正结果，因为「没有初始止损（理论亏损无界）」被要求补硬止损。实测：

| 硬止损 | 单笔净 | t | 最大单笔亏 |
|---|---|---|---|
| **无（对照）** | **+0.2513%** | +2.07 | −4.75% |
| 1.2% | **−0.0192%** | −0.17 | −2.13% |
| 2.0% | +0.0660% | +0.51 | −2.74% |
| 2.5% | +0.2509% | +2.20 | −3.23% |

> **「加风控」把一个正期望策略变成了零期望。**

**机制**：该策略的成交点本身在"急跌之后"，
入场后**经常先继续跌一段再反弹**。

紧止损恰好砍在反弹前 —— **止损保护的正是策略赖以生存的那批单子**。

### 配套发现

- **2.0% → 2.5% 是断崖**（+0.0660% → +0.2509%，3.8 倍），**不是平台** →
  少数关键赢单的最大浮亏落在 2.0–2.5% 之间。
  **这种临界值属于样本内巧合，不可外推。**
- "理论亏损无界"在样本内的实际表现是 **−4.75%**（6 笔套牢单全部持满 50 小时）。
  > **恐慌性措辞不等于真实风险，要看实测分布。**

## 13.2 事故二：两个各自有效的机制，叠加后互相抵消

| 单独 | 单笔净 | t | 组合 | 单笔净 | t |
|---|---|---|---|---|---|
| 结构止损（给空间） | +0.2541% | +1.00 | 两者组合 | **+0.0473%** | **+0.50** |
| 浮盈后收紧 | +0.2513% | +2.07 | | | |

**不是 1+1，是互相抵消。**

机制：
- 其中一个机制靠「**给足空间**」赚钱
- 另一个靠「**浮盈后收紧**」赚钱
- 组合后，前者在浮盈未达阈值时就砍掉"先跌后涨"的单
  （**正是后者能等到的**），后者再砍一批
- → **两边好处都丢、两边成本都付**

**邻域证据同样支持**：组合后 12 格邻域**只有 3 格为正**
（单用其中一个是 **27/36**）——

> **叠加不只拉低平均值，还把参数空间从平台变成了碎片。**

## 13.3 检查清单

- [ ] 加任何风控/过滤前，**先做档位扫描**（至少 6 档），看期望收益是升还是降
- [ ] 该参数是**平台还是断崖/锯齿**？（断崖 → 不可外推，只能当保险）
- [ ] 写清「改善了尾部多少」与「损失了多少期望」两个数，让使用者自己取舍
- [ ] 叠加机制前先问：**两者的作用方向冲突吗？**
      - "给空间" + "收紧" = **冲突**
      - "过滤信号" + "优化出场" = 通常不冲突
- [ ] 叠加后必须重跑**邻域**（单点变好可能是巧合，邻域变碎就是真差）

## 13.4 通用的两条

1. **风控的价值要单独论证** —— 它改善的是**尾部**（最大单笔亏损/回撤），
   **不是期望收益**。报的时候必须**分开报**，不能只说"加了更安全"。

2. **机制叠加的默认预期应该是「不叠加」或「打折」，不是「相加」。**
   只有在两者作用于**不同的失败模式**时才可能互补。

## 一句话

> **"更安全"是一个需要证明的假设，不是一个可以直觉接受的前提。**
