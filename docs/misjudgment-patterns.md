# 常见误判模式

**每一条都是真实踩过的坑。**

---

## 一、把 β 误认为 α（最高频）

| 现象 | 容易误判为 | 实际可能是 |
|---|---|---|
| 回测正收益 | 策略有效 | **吃了 β** |
| 训练测试一致 | 稳健 | **两段都在吃 β** |
| 所有参数都赚钱 | 参数不敏感 | **β 主导，与参数无关** |
| 长持仓收益更高 | 信号需要时间 | **时间越长，β 累积越多** |
| 某段特别赚 | 策略适应了行情 | **那段行情特别好** |

**共同点：都把 β 误认为 α。**

---

## 二、归因抢跑

**模式**：看到中间结果 → 编个合理解释 → 相信它 → 往下推。

| 编号 | 错误归因 | 真相 |
|---|---|---|
| 1 | 「所有配置都亏」→ 策略定位错 | 实际是出场规则把持仓压在信号无效区间 |
| 2 | 「某时长收益为正」→ 信号有效 | 实际那是 β |
| 3 | 「某个特征差异大」→ 找到过滤器 | 实际是**过程指标**，不是结果指标 |
| 4 | 「收益极度集中」→ 策略不可用 | 集中是**趋势策略的固有特征** |
| 5 | 「β 逐笔相加」→ α 极高 | β 被重复计算，α 虚高几十倍 |
| 6 | 「策略是熊市策略」→ 根因是毛收益塌了 | 实际根因是**选择效应**（没拆执行层） |

**共同模式：拿半成品中间量就往下推。**

**纠正**：
- 中间量必须**自洽**（单笔 × 笔数 ≈ 整体）
- 结论需要**多重独立证据**
- **先问"有没有更简单的解释"**

---

## 三、用错判据

**这是最隐蔽的一类** —— 因为它看起来像是在严谨。

| 错误判据 | 用在哪 | 为什么错 |
|---|---|---|
| Top5 集中度 | 趋势策略 | 那是**均值回归**的判据 |
| 持仓时长 / 长命率 | 判断收益 | **过程指标不能代替结果指标** |
| 「去掉最强段必须为正」 | 趋势策略 | 等价于要求"每段都赚"，**比正确判据更严** |
| 「笔数<3 的段不算」 | 分段统计 | **静默丢掉亏损小组** |

> **正确做法：先问三句**（判据适配吗 / 是缺陷还是固有特征 / 有经验的人怎么看）

---

## 四、被"漂亮数字"骗

| 可疑组合 | 通常意味着 |
|---|---|
| **t 值极高 + 持仓极短** | 成交价口径问题（见铁律 11） |
| 胜率 > 85% + 单笔收益极高 | 出场条件被记成有利价 |
| 样本极少 + t 极大 | 少数样本主导 |
| 收益曲线完美单调 | 可能有未来函数 |
| 单笔净异常高但笔数很少 | 小样本，无统计意义 |

> **"好得不合理"要当 bug 查，不要当发现报。**

---

## 五、工程性错误（不报错，但结果错）

| 错误 | 特点 |
|---|---|
| **静默降级** | 参数未传时用了默认值，结果悄悄变了 |
| **重叠持仓** | 每个信号都开一单，不检查是否已持仓 |
| **静默丢组** | 筛选条件与亏损相关，等于按结果筛样本 |
| **口径混用** | 同一项目里前后用不同成本/基准口径 |
| **路径重排** | 跳过一个信号会改变后续入场时点 |

**共同点：程序不报错，自洽性检查也通过。**

> **自洽性检查只能查算术错，查不出建模错。**

---

## 六、文档层面的隐性矛盾

| 现象 | 原因 |
|---|---|
| 读者问"这句什么意思" | 读到的是**早被推翻的旧结论** |
| 同一文档两个结论打架 | 修正时只改新位置，没清旧位置 |
| 中间版本被当成最终结论 | 多版本文档没有阅读提示 |

> **旧结论往往写得更具体、更抓眼，读者会优先信它。**

---

## 快速自查表

出结论前，把下面这些过一遍：

```
□ 我扣 β 了吗？β 给了区间吗？
□ 我分段看了吗？几段为正？
□ 我算 t 了吗？还差多少笔？
□ 交易数 ÷ 独立机会数 ≈ 1？（限价模式下要看区间是否交错）
□ 成交价用的是保守口径吗？
□ 我的判据适配这个策略类型吗？
□ 我说的"问题"是缺陷还是固有特征？
□ 分组汇总之和 = 总体合计吗？
□ 这份文档里还有被推翻的旧结论残留吗？
```
