# 铁律 8：基准与稳健性都必须给「区间」，不能只给一个数

## 8.1 β 自己也不是精确量

**已知 β 要扣，但很少有人提醒：β 本身也有抽样噪声。**

实测（同一段行情、同一批交易、同一参数，只换基准估法）：

| 估法 | β |
|---|---|
| 随机抽样，单个 seed | −3.45% |
| **20 个随机 seed 的区间** | **[−3.46%, +1.12%]**（均值 −0.86%） |
| 全时段均匀抽样 20000 次（确定性） | −0.58% |

**最大口径差 4.58pp**，而策略的单笔优势只有 0.05–0.08% 量级。

> **结论：净 α 的符号与量级可信，小数第二位不可信。**
> 汇报时写成 `净α +6.13%，区间 [+1.6%, +6.1%]`，不要只写 `+6.13%`。

## 8.2 ★ 「去掉最强段」只能当提示，不能当否决线

**这是一条自我纠正。** 曾用"去掉最强段后必须仍为正"当否决线，
把一个可用策略定性为"一次性有效（致命）"—— **这是错的。**

| 判据 | 结果 | 结论 |
|---|---|---|
| ❌ **错**：去掉最强段后必须仍为正 | 转负 | "致命" |
| ✅ **对**：**亏损段合计 ÷ 最大盈利段 < 30%** | 99% | "薄、处边界"—— **不是无效** |
| ✅ 对：最大单段亏损 | −4.46% | 可控 |
| ✅ 对：正 α 段占比（30–50% 即可） | 45% | 合格 |

**"去掉最强段后为负"只是"亏损段合计 ≥ 最大盈利段"（比值 ≥ 100%）的另一种说法。**

用它当否决线，**等于要求"每段都赚"** ——
那才是过拟合，而且正好否定了趋势策略的固有形态（见 [铁律 5](05-criteria-fit.md)）。

**正确的用法**：它是**"独立事件数够不够"的提示**。

> 比值接近或超过 100% → 说明全年的信息量 ≈ 一两个独立事件
> → **问题在样本量，不在形态。**

汇报时要写清是哪个问题（"薄/样本不足" vs "形态坏"），
**别把样本问题说成策略问题。**

```python
# 稳健性必做（趋势策略版）
segs  = [分段统计(s) for s in 所有段]
loss  = sum(x['net_alpha'] for x in segs if x['net_alpha'] < 0)   # 亏损段合计
best  = max(x['net_alpha'] for x in segs)                          # 最大盈利段
worst = min(x['net_alpha'] for x in segs)                          # 最大单段亏损
ratio = abs(loss) / best * 100        # < 30% 健康；> 100% = 独立事件数不足
pos   = sum(1 for x in segs if x['net_alpha'] > 0)
print(ratio, worst, f'{pos}/{len(segs)}')
```

## 8.2b 参数空间要「平滑」不要「锯齿」

**深度 × 等待时间**二维扫描实测（单笔净 %）：

| 深度 \ 等待 | 5分 | 10分 | 15分 | 20分 |
|---|---|---|---|---|
| 8bp | **+0.0817** | +0.0034 | +0.0076 | −0.0086 |
| 20bp | +0.1538 | +0.0858 | +0.0683 | +0.0596 |
| 30bp | −0.1598 | +0.0767 | **+0.2216** | +0.2147 |

- **8bp 那一行是锯齿**（5 分好、10–15 分几乎归零）→ 含大量抽样噪声，不是平台
- **30bp 那一行是平滑的**（10–20 分连续高位）→ 更可能是真结构

> **★ 判据：平缓的平台 > 尖锐的峰。**
> 单独一个好格子不值钱，成片的平滑好坏才值钱。

**★ 顺带一个机制性发现**：「等待时间」不是越长越好 ——
浅深度上**超过 5 分钟才成交的单子质量骤降**。

机制：信号后 5 分钟内回踩 = 短回调；超过 5 分钟才回踩 = 涨势已结束，成交即接刀。

> **一个有机制解释的参数 > 一个调出来的参数。**

## 8.3 汇报格式（强制）

```
净α  +6.13%   区间 [+1.56%, +6.14%]   亏损段/最大盈利段 = 99%   最大单段亏 −4.46%   正α段 5/11
├─ 是「形态坏」还是「样本薄」？ → 必须明确写出来
└─ 参数邻域是平台还是尖峰？ → 必须贴相邻格子的数值
```
