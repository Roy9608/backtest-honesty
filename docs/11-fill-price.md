# 铁律 11：成交价口径能凭空造出收益

**一律用保守口径。**

## 11.1 事故

一条止损规则跑出 **t = +5.01 / 净α +18.40%** —— 全场最优、史上第一次 t>5。

换成「成交价 = 触发那一分钟的收盘价」后：

| 口径 | 毛收益 | 净α |
|---|---|---|
| 乐观（按线位价成交） | +29.39% | **+18.40%** |
| **保守（按触发分钟收盘价）** | +4.64% | **−6.35%** |

**差 24.75pp。**

## 11.2 机制

规则写法是「止损线 = 上一根中轨，**盘中触线即按止损线价成交**」。

问题在于：**下跌趋势里，中轨位于价格上方** ——
实测 **73% 的笔数里中轨高于入场价（平均 +16bp）**。

于是「跌破中轨」从入场第一分钟就**恒成立**，
而成交价被记成一个**比市价高 16bp 的价**。

```
142 笔 × 16bp ≈ +23%    ← 正好解释那 +29% 的毛收益
```

> **这不是止损，是凭空造出的止盈。**

## 11.3 判定清单

凡是用「线位价格」当成交价的规则，必须全查：

- [ ] 该线位在触发时相对**市价**偏离多少 bp？（>0 = 乐观偏差）
- [ ] 该线位相对**入场价**在哪一侧？（**多头止损线必须在下方**；在上方 = 语义不成立）
- [ ] 同一规则跑两版：**成交价 = 线位价（乐观）** vs **成交价 = 触发分钟收盘价（保守）**，差多少？
- [ ] 报告里用的是哪一版？**默认必须是保守版**，乐观版只能作为偏差对照出现

### 配套诊断表（必出）

```
规则                    止损线触发   止损线-触发后市价   止损线高于入场价
中轨止损触线               142          +17.5bp            79%
```

## 11.4 ★ 反向线索：怎么在报给用户之前抓住它

> **「t 值异常高」+「持仓时长异常短」同时出现，几乎必是口径问题。**

本次线索就是这两个数字的组合：
**t = +5.01 而持仓中位数 1 分钟**。

一个止损线不可能在 1 分钟内被正常触发、还赚到 0.2%/笔。

> **"好得不合理"要当 bug 查，不要当发现报。**

### 同类可疑组合

| 组合 | 通常意味着 |
|---|---|
| t 值极高 + 持仓极短 | 成交价口径问题 |
| 胜率 > 85% + 单笔收益极高 | 出场条件被记成有利价 |
| 样本极少 + t 极大 | 少数样本主导 |
| 收益曲线完美单调 | 可能有未来函数 |

## 一句话

> **成交价怎么记账，比策略逻辑更能决定回测结果。**
