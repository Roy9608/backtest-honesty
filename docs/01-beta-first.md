# 铁律 1：先算 β 基准，再看 α

**任何"正收益"结论，必须扣除同期基准漂移。**

## 为什么

在任何单边行情里，**任何顺势策略都会"看起来有效"**。
但赚的钱可能纯粹来自大盘漂移，与策略本身无关。

一个真实的例子：

| 项 | 数值 |
|---|---|
| 策略 60 分钟平均收益 | +0.0674% |
| **β 基准（随机时点买入持有）** | **+0.0153%** |
| **真实 α** | **+0.052%** |
| 单笔成本 | 0.080% |
| **判定** | ❌ **α < 成本 → 不成立** |

在那个阶段，报告里所有"正收益"配置，本质上都是 `β − 手续费`。

## 怎么做

```python
import random
random.seed(7)

# 1. 随机时点买入持有（10000 次模拟）
mv = []
for _ in range(10000):
    k = random.randint(0, len(px) - h - 1)
    p0, p1 = px[k].c, px[k + h].c
    if p0 > 0:
        mv.append((p1 - p0) / p0 * 100)
beta_base = sum(mv) / len(mv)          # ← 这就是 β 基准

# 2. 真实 α
alpha = strategy_return - beta_base

# 3. 关键判据
#    α > 单笔成本  →  策略可能成立
#    α < 单笔成本  →  策略不成立（无论回测数字多好看）
```

## 三个必须注意的点

### 1. β 的持仓时长要对齐

β 基准必须用**和策略相同的平均持仓时长**去模拟。
策略平均持仓 60 分钟，β 就用 60 分钟——用别的时长比是没有意义的。

### 2. β 不能逐笔相加

⚠️ **这是比"忘记扣 β"更隐蔽的错误。**

如果策略持有多笔，且持仓时间重叠，那么把每笔的 β 直接相加，
会让 β 被**重复计算几十遍**。

| 错误做法 | 后果 |
|---|---|
| 把每笔的 β 逐笔相加 | β 被重复计入（重叠时段反复算） |
| 极端案例 | 曾算出 α = 成本的 **517 倍**，而实际净收益是 **−53%** |

**正确做法**：用**单笔平均对照**，或**分段扣**（按时间段计算 β，一个时段只扣一次）。
并加**自洽性验证**：`单笔净 × 笔数 ≈ 整体净`。

### 3. β 本身也要给区间

见 [铁律 8](08-interval.md)。β 不是精确量，它的抽样噪声可能比策略优势还大。

## 一句话

> **回测数字好看 ≠ 策略有效。先扣 β，再看 α，最后比成本。**
