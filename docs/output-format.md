# 报告策略结论时的输出规范

**三条缺任何一条，都不能说"策略有效"。**

---

## 一、标准表格（必须包含全部字段）

```markdown
| 指标 | 数值 |
|---|---|
| 策略收益 | +X.XX% |
| β 基准（同期随机买入持有） | +X.XX%　**区间 [Lo, Hi]**（多 seed） |
| **真实 α** | **+X.XX%** |
| 净α | +X.XX%　**区间 [Lo, Hi]** |
| 单笔成本 | X.XXX% |
| **α vs 成本** | ✅ 超过 / ❌ 未超过 |
| 正收益段数 | X / Y |
| **最强段贡献占比** | XX%　**去掉后净α = ±X.XX%** |
| **执行方式** | 市价 / 限价 Xtick（成交率 XX%，价差 Xbp） |
| **单仓不变量** | 交易区间有无交错（应：无交错） |
```

---

## 二、必须写明的一句话结论

在表格之外，用**一句话**说清判定，且必须包含三要素：

```
判定：{成立 / 不成立 / 样本不足}
理由：α 是否超过成本 + β 是否给了区间 + 去掉最强段后是否仍成立
```

**示例**：

> **判定：不成立。**
> 理由：α 为 +0.052%，低于单笔成本 0.080%；
> β 区间为 [−0.196%, +0.386%]（跨 0）；去掉最强段后净 α 转负。

---

## 三、区分"形态问题"和"样本问题"

**这是最容易混淆、也最容易误伤策略的一点。**

| | 形态问题 | 样本问题 |
|---|---|---|
| 表现 | 亏损段合计 ÷ 最大盈利段 ≥ 100% | 同样表现，但 t 值极低 |
| 含义 | 策略本身不可用 | **策略可能可用，但数据不够** |
| 处置 | 放弃 | **继续采集数据** |

**不要把它们混为一谈 —— 把样本问题说成策略问题，会误杀一个可用方案。**

### 区分方法

```
若 t < 2 且置信区间跨 0  →  优先归因为「样本问题」
若 t > 2 但亏损段占比过高  →  可能是「形态问题」
```

---

## 四、参数必须给邻域，不能只给最优值

**单独一个最优参数值是没有意义的。**

报告里必须包含：

```markdown
### 参数邻域（必须贴出相邻格子的数值）

| 参数 A \ 参数 B | B1 | B2 | B3 |
|---|---|---|---|
| A1 | +0.061 | +0.082 | +0.111 |
| A2 | ... | ... | ... |

判读：{平滑平台 / 锯齿 / 孤峰}
```

> **平缓的平台 > 尖锐的峰。**
> 单独一个好格子不值钱，成片的平滑好坏才值钱。

---

## 五、负面结论也要报得同样详细

**失败的结果如果记录得够诚实，比成功更有用。**

一个合格的负面结论报告应包含：

- [ ] 最终判定（明确写"不成立"/"不能上实盘"）
- [ ] 依据（哪几个数字支撑这个判定）
- [ ] 已排除的可能性（"不是参数没调好，是 XXX"）
- [ ] 仍然可用的部分（方法论 / 工具 / 部分结论）
- [ ] 若继续，下一步该做什么

---

## 六、这些表述不要用

| ❌ 不要写 | ✅ 改成 |
|---|---|
| 「效果不错」 | 「单笔净 +0.0817%，t=0.54」 |
| 「收益约 XX%」 | 「收益 +X.XX%」 |
| 「数据量偏少」 | 「n=75，达到 t=2 需 1030 笔」 |
| 「表现稳健」 | 「11 段中 5 段为正，亏损段合计/最大盈利段 = 99%」 |
| 「有一定效果」 | 明确说明：超过成本了没有 |

> **禁「≈」、禁模糊词、取不到的数字标"未获取"、实际数值必引来源。**
