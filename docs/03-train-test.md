# 铁律 3：训练/测试一致 ≠ 策略有效

**牛市里训练集和测试集都涨，看起来"一致"，但可能双方都在吃 β。**

## 为什么

最常见的误解是："训练集和测试集表现一致，说明没有过拟合，策略是有效。"

**这句话漏掉了一种情况**：如果两个窗口都是单边上涨行情，
那么**任何做多策略在两个窗口都会赚钱**——一致性来自行情，不来自策略。

## 四种检验，缺一不可

| 检验 | 说明 | 能发现什么 |
|---|---|---|
| **训练/测试切分** | 样本外是否复现 | 过拟合 |
| **Walk-Forward** | 多段滚动验证 | 是否靠某几段 |
| **β 基准对照** | **扣掉大盘漂移** | **是否只是吃了行情** |
| **分段涨跌** | 收益来源分布 | 收益是否集中 |

**只做前两个，会漏掉最根本的 β 混淆。**

## Walk-Forward 的正确做法

不要只做一次切分。**滚动多段，统计通过率。**

```
切分方式：训练 → 测试 → 窗口前移 → 再训练 → 再测试
统计：几轮通过了？几轮是"训练正 + 测试负"？
```

一个真实教训：某策略的 Walk-Forward 结果是
**6 段中仅 2 段为正，滚动 5 轮中仅 2 轮为正**，
且"训练正 + 测试负"出现了 **3/5 次**。

这已经是很明确的过拟合信号了。

## 另一个陷阱：样本外为负 ≠ 策略失效

反过来说也成立。**样本外为负，也要查原因。**

有一种情况是：测试期恰好落在**策略不适配的行情类型**里。

| 情形 | 结论 |
|---|---|
| 训练正、测试负，且两个窗口行情类型相同 | **大概率过拟合** |
| 训练正、测试负，但测试期是另一类行情 | **要查是"策略失效"还是"行情不适配"** |

区分这两者，要看 [铁律 5](05-criteria-fit.md)（判据适配）和
[铁律 14](14-four-way-decomposition.md)（收益分解）。

## 一句话

> **一致性可能来自策略，也可能来自行情。先确认是哪一个。**
